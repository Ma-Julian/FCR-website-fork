# Partner logos

One SVG per partner, named after its `id` in `data/integrations.json` (`gnosis.svg`).
Colours are `currentColor` so the strip can tint them. A partner without a file shows
its name only.

Placeholders until partners send their official files:
- `gnosis.svg`: the owl mark from Gnosis's public media kit, github.com/gnosischain/media-kit (`Logos/Owl_Logo - Mark.svg`).
- `chainlink.svg`: the Chainlink mark from Simple Icons (simple-icons on npm, v16.35.0).
