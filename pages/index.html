            Easy to adopt

            FCR runs in your node or via your RPC provider. All you do is flip a flag, read a different block, and test for production.

            − eth_getBlockByNumber("finalized")
            + eth_getBlockByNumber("safe")
            • Turn it on. Enable FCR in Lighthouse, Prysm, Lodestar or Nimbus, or use an RPC provider that serves it.
            • Be able to handle reorgs. While reorgs would only occur in extremely exceptional circumstances, you should be able to handle them.
