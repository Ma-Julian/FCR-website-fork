# Get support

Most integrations need no help: run a node with FCR and read `safe`. Start with the [Quick start](./integrate/quick-start) and the guide for what you run.

## Still stuck?

- **Talk to the FCR team:** message Julian Ma on Telegram ([@julianzma](https://t.me/julianzma)), on X ([@_julianma](https://x.com/_julianma)) or by email ([julian@ethlabs.org](mailto:julian@ethlabs.org)). Tell us what you run and where you're stuck.
- **Email:** fastconfirm@ethereum.org

## Security issues

Report vulnerabilities through the [Ethereum Foundation bug bounty](https://ethereum.org/bug-bounty/), not in public channels.

## Follow the work

- Specification: [consensus-specs PR #4747](https://github.com/ethereum/consensus-specs/pull/4747)
